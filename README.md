🏨 GuidedIstanbul – Otel Rezervasyon Sistemi (MVC)

GuidedIstanbul, otel rezervasyon işlemlerinin API’ler üzerinden gerçekleştirildiği, MVC mimarisiyle geliştirilmiş bir otel rezervasyon projesidir.
Proje, modüler yapısı sayesinde farklı projelere ve sektörlere kolayca uyarlanabilir bir altyapı sunar.

🎯 Projenin Amacı

Otel rezervasyon süreçlerini merkezi bir yapı üzerinden yönetmek

API tabanlı rezervasyon sistemleri geliştirmek

MVC mimarisi ile sürdürülebilir ve genişletilebilir bir proje oluşturmak

🚀 Özellikler

🏨 Otel listeleme

🛏️ Oda bilgilerini görüntüleme

📅 Tarihe göre müsaitlik kontrolü

📝 Otel rezervasyonu oluşturma

🔌 API üzerinden rezervasyon işlemleri

♻️ Diğer projelere entegre edilebilir yapı

🧱 Mimari Yapı

Proje ASP.NET MVC mimarisi kullanılarak geliştirilmiştir.

MVC Katmanları

Model

Otel, oda ve rezervasyon veri yapıları

View

Kullanıcı arayüzü (HTML / CSS / JS)

Controller

Kullanıcı istekleri ve API iletişimi

API Yapısı

Rezervasyon işlemleri API’ler üzerinden yapılır

Aynı API’ler mobil veya farklı web projelerinde tekrar kullanılabilir

🛠️ Kullanılan Teknolojiler
Backend

ASP.NET MVC

RESTful API

JSON

Frontend
